# Plexus

Year-level medical question bank. One HTML file. Progress stays in the browser.

**Live:** [https://sjeraldxx.github.io/plexus/](https://sjeraldxx.github.io/plexus/)

If that URL 404s for a minute, turn Pages on once:

1. Open [Settings → Pages](https://github.com/sjeraldxx/plexus/settings/pages)
2. Build and deployment → **Deploy from a branch**
3. Branch **main** / folder **/** (root) → Save

## CSV import

`question,option_a,option_b,option_c,option_d,correct,rationale,coverage`

`correct` can be A–D, 1–4, or the option text.
